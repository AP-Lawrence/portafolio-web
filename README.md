# Alexander Suárez | Backend Developer Portfolio

Portafolio personal desarrollado con **HTML5, Tailwind CSS y CSS**, diseñado para presentar mi perfil como desarrollador, mis habilidades tecnológicas, intereses y proceso de aprendizaje en el mundo del desarrollo de software.

El proyecto utiliza una estética moderna y minimalista, con una temática futurista, colores oscuros y detalles en verde lima.

##  Enlaces

- **Sitio web:** https://github.com/AP-Lawrence/portafolio-web
- **Repositorio:** https://github.com/AP-Lawrence

##  Descripción del proyecto

Este portafolio tiene como objetivo presentar quién soy, cuáles son mis intereses y qué tecnologías estoy aprendiendo actualmente.

El diseño está organizado en diferentes secciones para facilitar la navegación y ofrecer una experiencia visual agradable tanto en dispositivos móviles como en computadores.

### Secciones

- **Inicio:** Presentación personal, nombre y enfoque profesional como Backend Developer.
- **Sobre mí:** Información sobre mi perfil, motivaciones e intereses en la programación.
- **Habilidades:** Tecnologías y herramientas que estoy aprendiendo y utilizando.
- **Intereses:** Información sobre mis intereses en electrónica, historia, mitología, finanzas y negocios.
- **Footer:** Enlace a mi perfil de GitHub e información del desarrollador.

##  Diseño responsive

El proyecto utiliza las clases responsive de Tailwind CSS para adaptar su contenido a diferentes tamaños de pantalla.

Se implementaron los siguientes prefijos:

- `sm:` Adaptaciones para pantallas pequeñas.
- `md:` Distribución de contenido para tablets y pantallas medianas.
- `lg:` Adaptaciones para pantallas grandes.

También se utilizaron herramientas de Tailwind CSS como:

- Flexbox y CSS Grid.
- Espaciados y dimensiones.
- Colores y fondos personalizados.
- Bordes y sombras.
- Efectos hover y transiciones.
- Tipografías y tamaños de texto.
